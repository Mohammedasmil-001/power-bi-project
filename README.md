# power-bi-project
sample-superstore-sales-analysis-powerbi
Power BI Sales Analysis Dashboard
📌 Project Overview
This project presents an interactive Power BI dashboard designed to analyze sales performance and uncover meaningful business insights.
The dashboard helps stakeholders understand trends, performance metrics, and key drivers influencing sales and profitability.

🎯 Objectives
Analyze overall sales performance
Identify trends across time, regions, and categories
Track key performance indicators (KPIs)
Support data-driven business decisions through visualization
📂 Dataset
Source: Practice / Business dataset
Format: CSV / Excel (loaded into Power BI)
Data includes sales, profit, categories, regions, and time-based attributes
🛠 Tools & Technologies
Power BI Desktop
Power Query (Data Cleaning & Transformation)
DAX (Measures & Calculations)
Interactive Visualizations
🔄 Data Preparation
Removed duplicates and null values
Standardized column names
Created calculated columns and measures
Modeled relationships between tables
📊 Dashboard Features
KPI cards (Sales, Profit, Growth)
Trend analysis using line and bar charts
Category and region-wise performance
Interactive filters and slicers
Drill-down functionality for deeper analysis
📈 Key Insights
Identified top-performing categories and regions
Observed seasonal and yearly sales trends
Highlighted areas with high sales but low profitability
Enabled quick comparison using interactive visuals
📁 Project Files
powerbi project.pbix – Power BI dashboard file
🚀 Conclusion
This Power BI project demonstrates the ability to transform raw data into meaningful insights using visualization and analytics.
The dashboard provides a clear and interactive way to monitor performance and support strategic decision-making.
